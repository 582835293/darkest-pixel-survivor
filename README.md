# 血夜幸存者 · Darkest Pixel Survivor

一个可以直接打开游玩的单文件像素生存游戏，支持电脑与安卓浏览器、2–3 人联机。

**[在线游玩](https://582835293.github.io/darkest-pixel-survivor/)** · [项目源码](https://github.com/582835293/darkest-pixel-survivor)

![联机大厅](assets/lobby.png)

## 开始游玩

1. 所有人用正常浏览器打开在线游戏。
2. 填写名字。房主可以填写房间名称，再选择“无密码 · 公开房”或“有密码 · 私密房”后创建，朋友输入房号加入；密码房还需填写密码。开房会先检测房号是否被占用。
3. 想直接找人一起玩，可以点击“快速匹配公开房”，或点击“浏览公开房间”查看名称、房号、房主、人数与状态后点“加入”。列表只展示同版本无密码房，满员房间不可加入；自动匹配优先选择尚未出征的队伍。
4. 队伍出现后点击“出征”。角色、关卡及连接线路可在大厅的折叠栏中调整；声音和特效在“菜单 → 系统设置”中调整。

也可以下载 `index.html` 在本地打开。手机文件管理器可能使用 `content://` 预览，此时麦克风权限可能不可用；需要语音时使用 HTTPS 在线版。

GitHub Pages 提供游戏文件；游戏数据优先在玩家之间通过 WebRTC P2P 传输。托管服务不充当游戏服务器。

## 联机玩法

- 房主同步共享怪物、掉落和战场进度。经验水晶、金币和道具先到先得。
- 每增加一名玩家，怪物血量以及掉落经验、金币增加 60%，怪物伤害不额外增加。
- 猩红血棘每亲自击杀 10 只怪触发一次回血，使用击杀者自己的流派等级；流血和炸弹击杀同样归属来源玩家，治疗溢出转为自己的护盾。
- 队友倒地后，单人在尸体旁连续站立 6 秒可以救援；两人同时救援为 3 秒。一人离开后由剩余队友继续，所有救援者离开才重置进度。升级保护或打开菜单的玩家不能救援。
- 倒地玩家可选择队友观战；尸体留在原处，复活后恢复自己的镜头。打开菜单时观战条自动隐藏，关闭后恢复选择。
- 队友头顶和屏幕边缘显示距离、方向；小地图标有“点击展开”，与右上角“菜单”按钮分开；点击展开以自己为中心的大地图。同心圈按 100、250、500、1000、2000、4000、8000 游戏距离递增，近处更细，远处压缩；带队友、待救援、怪物、首领、神龛和秘宝图例；经验、金币及普通掉落道具不在大地图显示。大地图不暂停战斗。
- 队友普攻、蓄力、战技、终结技、护盾及光环与本机共用原版绘制函数，保留技能原色、形状、粒子、残影和普通/觉醒差别，不随角色皮肤变色。同步真实剑阵数量、旋向、落点、陷阱和飞轮接取点；仅绘制，不重复结算伤害。队友特效透明度继续独立生效。
- “菜单 → 系统设置”统一调整聊天语音、背景音乐、游戏音效（0–100%）及音乐开关，并分别调整自身/队友技能特效透明度（0% 不透明，100% 隐藏），带推荐档位且自动保存到本地。自身设置仅改变技能特效显示，角色、敌方弹道和危险预警仍正常显示。
- 升级玩家暂时隐匿并受到保护，最多有 20 秒选择；超时随机升级，其他人继续战斗。
- 连续重刷优先显示当前可选池里尚未出现的技能，抽完一轮再随机循环。超武不会每次固定占满候选，流派 2 种/配件 3 件的限制会在选卡页提示；解锁条件保持不变。
- 秘宝的方向提示只显示图标和距离，完整名称可在图鉴和近处祭坛查看。
- 右上角“菜单”、技能树、系统设置、商店、存档、开发者、队伍房间以及大地图均不会暂停多人战场；打开者停止操作，获得最多 10 秒菜单无敌，顶部显示剩余秒数。嵌套切换菜单共用期限；关闭菜单立即结束保护，超时留在菜单内仍会受伤。菜单中的玩家不参与拾取和救援。单人菜单仍正常暂停，大地图仍实时更新。
- 只有房主菜单中的“暂停全队游戏”可以暂停整场对局，再点“恢复全队游戏”恢复；关闭菜单不会自动恢复全队。
- 磁铁为实际拾取者吸引全图已有经验水晶，经验按每颗水晶最终拾取者结算；其他玩家仍可在水晶飞行途中贴身抢拾。
- 联机结束后点“返回队伍房间”，原房号、队友、聊天和语音均保留；回营地调整天赋也不会退队，可在原队伍继续出征。只有“退出房间”会离开队伍。菜单中的“返回队伍房间”保留本局，点出征可继续。
- 房间文字聊天支持送达确认，弹幕默认显示在页面最上层，覆盖大厅和游戏弹窗，也不会阻挡触控。
- 语音支持开启麦克风、仅收听、静音和退出，使用独立 WebRTC 音频连接。客机之间媒体连接不通时可自动通过已加入语音的房主转发，房主仅收听也可以；直连正常时不会重复播放转发音轨。

## 连接与语音

大厅“连接线路”显示实际承载游戏数据的线路和往返延迟，标记“当前”。直连可用时优先直连，直连不可用时尝试内置公共线路。房主可调整备用线路，队友自动跟随。

公开 STUN 和消息代理没有服务质量保证，项目也没有内置付费 TURN。IPv6 地址可用不等于双方一定能连通，语音与游戏数据的连接也分别验证。详情见 [联网机制](docs/NETWORKING.md)。

房间最多 3 人。匹配与密码验证由房主确认，满员时拒绝新成员；异常掉线的房间公告约 20 秒失效。房号查重使用公共消息服务中的在线登记，不是集中数据库的强一致锁；不同网络临时隔离时仍可能出现同号，恢复互通后会自动换号。每个房间另有独立随机标识，所以同号不会把两个战场合并。

所有人都需要刷新到 **R13**。不同版本的房间不会匹配，旧版客户端会收到更新提示。安全入房需要浏览器 Web Crypto，受限的手机文件预览器请改用 HTTPS 在线版。密码不保存到存档，也不通过公共线路明文发送；这是朋友组队的入房控制，不是账号认证或针对已入房成员的反作弊系统。

在“交流”中点击“开启麦克风”才会申请采音权限。每位想收听的玩家都需要加入语音；选择“退出语音”或离开房间会停止采音。项目不提供语音录制功能。

GitHub Pages 的访问情况取决于地区和运营商，本项目不承诺全国所有网络均能访问。网站加载速度与联机数据往返延迟是不同的指标。

## 客机开发者权限

单人及房主仍使用原开发者密码 `114514`。房主入房后在“开发者”面板解锁，设置 4–32 字符的客机专用密码；客机输入该密码只会提交申请，房主必须再点“同意”。房主可拒绝、撤销或修改密码，退出/进入新房间后重新申请。授权依赖房主在线刷新，失联后会过期；专用密码不保存、不明文发送。公开源码游戏中的这些权限用于朋友之间管理，不是针对修改客户端的反作弊保护。

## 存档

存档保存在每位玩家自己浏览器的 `localStorage`，项目没有云存档服务。更新同一站点时可以继续使用原存档；换设备、浏览器、域名，或者清除网站数据后需要迁移/恢复。

从本地 HTML、其他托管网址迁移到这里：先在旧游戏“存档管理”中导出完整 `PSSAVE_` 存档码，然后到新网页导入一次。建议定期导出备份，不要把个人存档提交到仓库。

## 开发与检查

`index.html` 是完整的游戏源码和可分发文件，使用原生 HTML、CSS、JavaScript 与 Canvas，不需要构建步骤或运行时依赖。修改后可直接打开，或在本机使用静态文件服务预览。

```bash
npm run check

# 可选：安装浏览器测试依赖并运行隔离的联机测试
npm install
npx playwright install chromium
npm test
```

浏览器测试使用虚拟麦克风和模拟房间发现，不代表实际手机运营商或音质测试。测试方式与边界见 [验证说明](docs/TESTING.md)。

## 项目结构

```text
index.html       完整游戏，可独立分发
assets/          界面截图
docs/            联网机制、验证记录
scripts/         JavaScript 语法检查
tests/           隔离浏览器集成测试
```

GitHub Pages 从 `main` 分支根目录发布，根目录 `.nojekyll` 保持原样提供静态游戏文件。更新游戏时提交 `index.html` 即可。
