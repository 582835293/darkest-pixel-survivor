## 一局里能玩到什么

- **从小技能长成整套构筑。** 普攻、蓄力、战技、大招逐级进化；搭配配件解锁觉醒，再选择蓄力攻击的两条分支。
- **五个职业，五种战斗节奏。** 近战引爆流血、冰闪连锁控场、走位接回飞轮，锁定目标引导炮群轰炸，或用圣域与羽翼阵治疗、护盾和审判敌人。
- **选两条流派，做自己的取舍。** 七种流派中每局最多携带两种，配件最多三件。重刷优先给尚未出现的候选。
- **共享战场，掉落要抢。** 队友面对同一批怪物；经验水晶、金币、道具先到先得。每多一名玩家，怪物血量与掉落经验、金币增加 60%。
- **倒地还有下一次机会。** 队友站在尸体旁可救援；普通玩家一人需要 6 秒，两人一起 3 秒；祷师救援速度加倍，单人 3 秒，与一位普通队友协作 2 秒。倒地后可以切换队友视角。
- **打完继续组队。** 一局结束返回原队伍房间，保留房号、聊天和语音，再出征下一局。

![满级机匠展开十座炮台与重装机甲，向尸潮发射交叉磁轨束](assets/screenshots/engineer-endgame.png)

*烬铁机匠：满级觉醒后 6 座常规炮台与 4 座大招支援形成十炮台阵地；自己和炮群共同释放金色磁轨束。*

机匠的战斗循环是 **铺炮网 → 普攻锁定并攒热 → 满热三轮集火 → 蓄力或过载轰炸**：

- 普攻升级为 6 枚贯穿锁定钉，每第三次觉醒普攻附带双追踪火箭；手持攻击指定炮群优先目标。
- 热能满时自动触发炮网三轮齐射；也可以提前蓄力，消耗已有热能强化重炮。
- 磁雷先牵引附近小怪，再延时爆破，把敌人聚进交叉火力范围。
- 蓄力二选一：**炮网贯穿齐射**让自己与全部炮台共同开炮；**追踪火箭弹幕**发射 6–10 枚弧线追踪火箭，并指挥炮群集火。
- 觉醒大招展开重装机甲与四座限时支援炮台，持续9秒巡航轰炸。浮游炮从Lv.1一门逐步成长为Lv.5四门，自动瞄准540px内的敌人，每0.45秒每门发射一枚爆炸弹，觉醒后每门两枚；大招期间普攻间隔×0.65，蓄满时间×0.70，结束恢复。常规炮台也有寿命，需要补充与调整阵地。

![机匠大招的四门浮游炮转向附近敌人，发射亮芯爆炸弹](assets/screenshots/engineer-cannons.png)

*浮游炮阵实机演示：缩小外围轮廓、移除粗支架，中心保留角色和走位空间。炮管瞄准与实际弹道共用方向；空场待机不假开火，开炮后才出现后坐、炮口焰和排烟。觉醒后使用双炮管，伤害仍由原有命中系统结算。*

## 曙光祷师：能救队友，也能独自打成型

![曙光祷师展开六翼圣光与庇护圣域，审判围拢的怪潮](assets/screenshots/healer-endgame.png)

- **降辉圣光：** 普攻直接照落到怪物头顶，立即结算，无需等待飞射物。Lv.1–5分别审判1–5个目标，觉醒为七道圣光，附带小范围溅射；每次攻击积攒10祷光，上限100。
- **蓄力·祷光绽放：** 初始蓄满0.7秒，释放间隔约0.735秒；无天赋Lv.5分别约0.459秒和0.482秒；连发会等到冷却就绪再释放，避免空震屏。消耗祷光造成范围伤害；至少25点祷光时同时治疗附近玩家。满级二选一：更广的**救赎圣歌**，或10–14道贯穿光束的**审判光轮**。
- **回春祷言：** 立即治疗附近存活队友并加盾；溢出治疗的一半转为护盾，祷师带来的护盾最高为目标生命上限的35%。
- **庇护圣域：** 放置7秒圣域，每秒治疗，同时持续灼伤怪物。换阵地需重新部署。
- **六翼曙光：** 群疗、护盾和持续圣光审判；觉醒后延长至8.5秒，每轮最多审判8个目标（Lv.5觉醒）。
- **曙光返照：** 受到怪物攻击后，把护甲减伤后实际承受伤害的50%返还给实际攻击者，护盾吸收也计入；触发间隔0.5秒。反伤不暴击，也不再重复吃等级或其他伤害倍率。
- **救援速度×2：** 仍需站在倒地队友身边；祷师单人3秒，与普通队友一起2秒。治疗不会远程复活尸体。

全图冻结只停止怪物行动，祷师仍能持续蓄力、治疗与审判。突破与冷却秘宝形成的快速治疗也按实际冷却验证。

四项技能各有觉醒，沿用既有七流派与三配件限制。联机治疗由房主检查范围、状态和冷却，分别发给实际队友；重复消息不会重复回血。菜单、选卡和倒地期间停止自身施法。

## 从一门炮长成火力网

五位猎手的大招都能从Lv.1升至Lv.5，满级后再解锁觉醒。每级提高伤害、缩短冷却，技能轮廓与施法纹样随等级增强；各职业还有自己的数量、范围或持续时间成长。

| 浮游炮门数 | 1 | 1 | 2 | 3 | 4 | 4（双炮管） |
| 临时支援炮台 | 0 | 1 | 1 | 2 | 3 | 4 |

游侠每接回一枚飞轮，都可独立返还战技冷却并回血；没有每轮或累计次数上限。大招按一半比例返还，圣盾不返还。接轮、走位、再次投掷可以形成连续循环。

## 治疗看得见，贡献记得住

祷师施加治疗或护盾后，队友头顶会出现数值，页面也会短暂显示“谁治疗了谁”；房主与客机都能看到。结算区分有效回血与实际新增护盾，满血溢出不虚增治疗量。

战局结束显示全队伤害、治疗、护盾、击杀和救援，并综合角色贡献、存活时间与倒地情况给出C到S档评定。**S+只在通关时授予全队最强的一人**，治疗辅助也能拿到。短暂汇总结束后即可返回原队伍继续出征。

## 商人的一次机会

在1分30秒、6、12、18、24分钟附近，会出现神秘商人，小地图与大地图均有标记。靠近后按E或点“访问商人”。

- 随机出售尚未选择的技能、流派和装备，也出售已有技能的升级，通常100–140金币，觉醒180金币。购买时仍需满足格子和前置条件。
- 花数百金币卸下战技、流派、装备或秘宝，腾出格子。卸下的主动技需要重新学习；已形成的觉醒不会因卸下配件而退化。
- 随机出现1–2位已战胜首领的雇佣选项，约480–780金币；每位玩家本局最多雇佣两位。友军跟随并攻击，击杀收益归雇佣者。
- 每个商人只接待第一位访客的一次访问，访问期间可买多件；离开或90秒到期后离去，全队都不能再次访问。购买会再次检查金币与资格，重复消息不重复扣款。

## 喊朋友一起玩

1. 所有人用正常浏览器打开 **[在线版](https://582835293.github.io/darkest-pixel-survivor/)**，填写昵称、选择角色。
2. 房主创建公开房或密码房，朋友输入房号加入。也可以浏览公开房间列表，或快速匹配公开房。
3. 队伍到齐后点击“出征”。需要语音时打开“交流”，再点“开启麦克风”申请权限。

更新游戏后，所有队友确认同一版本，再重新开房。

房间支持命名、房号查重和人数限制。连接优先尝试 P2P 直连，大厅的“连接线路”会显示实际路径与往返延迟；房主可以选择备用线路。

- **交流能边打边看：** 文字默认以顶层弹幕显示；支持 WebRTC 语音、仅收听、静音和退出语音。
- **升级不用等队友：** 升级者暂时受到保护，有 20 秒选卡，超时随机选择；其他玩家继续战斗。
- **菜单与全队暂停分开：** 多人打开菜单只停止自己的操作，并获得最多 10 秒菜单无敌，切换嵌套菜单不重新计时。到期继续停在菜单仍会受伤。只有房主的专用按钮可以暂停、恢复整场对局。
- **方向和队友随时可查：** 屏幕边缘有队友箭头与距离，点击小地图可展开带距离圈的大地图。
- **特效与音量自己调：** “菜单 → 系统设置”分别调整自己/队友技能透明度、语音、音乐与音效音量。

## 操作

| 操作 | 电脑 | 手机 |
| --- | --- | --- |
| 移动 | WASD / 方向键 | 左侧摇杆 |
| 普攻 / 蓄力 | J / 空格，长按蓄力 | 点击 / 长按普攻 |
| 两项战技 | K / L | 对应技能按钮 |
| 终结技 / 护盾 | U / I | 对应技能按钮 |
| 菜单 | P / 右上角“菜单” | 右上角“菜单” |
| 访问附近商人 | E | 靠近后点击访问按钮 |

可开启普攻连发辅助，把注意力留给走位与技能。出征与关闭菜单/聊天后自动归还战场焦点，并清除残留按键；兼容物理键位与旧式按键事件，聊天时不触发技能，切出窗口会清除按住状态。Chrome、Edge、Firefox已分别用正常动画循环测试五职业移动与K/L实际伤害。单人菜单会正常暂停。

多人开发者权限默认关闭，由房主在开发者面板设置本房间密码；客人验证后还需房主明确批准。换密码或关闭权限会撤销已有授权，退房后密码与授权清空。单人的隐藏口令不会出现在界面提示中。

## 存档与访问

返回营地会结束并清理本局，金币与永久天赋保留。“进入战场”始终开启新局，不再在营地显示“继续上次战局”。联机结算后保留队伍和语音。若浏览器意外关闭，可在“存档管理”手动恢复单人断点。

存档保存在**各自浏览器的 `localStorage`**，没有云存档。更新同一网址可继续使用原存档；换设备、浏览器、域名，或从本地 HTML 迁移时，可在“存档管理”导出完整 `PSSAVE_` 存档码，再到新环境导入。建议定期备份。

游戏本体是一个 HTML 文件，也可以下载 [index.html](index.html) 本地打开。手机文件预览器的 `content://` 环境可能无法申请麦克风权限，需要语音时请使用 HTTPS 在线版。

GitHub Pages 只分发游戏文件。P2P 连接取决于双方网络；公共备用线路没有服务质量保证，当前也未内置付费 TURN。具体机制、房号查重边界与线路说明见 [联网文档](docs/NETWORKING.md)。

## 开发与开源

游戏逻辑、界面、原版特效和像素精灵均在 [index.html](index.html) 中；游戏本体无需安装 npm 依赖。仓库当前388项检查覆盖真实本地 RTC、技能与伤害归属、房间、语音、存档、界面，以及原版/队友特效对比。

```bash
npm ci
npx playwright install chromium
npm run check
npm test
```

R22完整检查集为388项、29套，覆盖真实键盘、伤害与治疗归属、客机交易和丢包去重、友军收益、旧存档、脉冲位移与原版特效一致性。另执行本版150场受控数值场景：四档相同升级投入，100场单体/群体木桩、50场实际AI追击；详见[测试方法与数据](docs/BALANCE.md)。这些检查不等于真人通关或手机跨网性能实测。

开发测试可通过 `PLAYWRIGHT_EXECUTABLE_PATH` 指定已有 Chromium / Edge。详见 [验证说明](docs/TESTING.md)；测试结果与临时画面保存在被 Git 忽略的 `test-results/`。

运行 `npm run icons` 可导出原创 PNG 图集及坐标表。运行 `npm run screenshots` 可重建首页的满级构筑演示图：通过真实升级卡配置角色，再生成怪潮并捕捉实时游戏画面。

运行 `node scripts/capture-r22.cjs` 可重建追猎脉冲、圣光普攻、商人、成就、图鉴与结算布局示例；结算示例使用预置统计，脚本不连接公开玩家房间。

欢迎通过 [Issues](https://github.com/582835293/darkest-pixel-survivor/issues) 提交问题和玩法建议。报告联机问题时，附上游戏版本、双方设备/浏览器、实际连接线路与 RTT，会更方便排查。
