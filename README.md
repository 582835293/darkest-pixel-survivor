## 这一夜，多了点蒜味

加了几处对《吸血鬼幸存者》的玩法致敬，以原创像素绘制，融入血夜的角色和世界观：

- **蒜香护符 → 黑蒜晨星。** 所有职业都可选的装备，占三格之一。每0.85秒伤害并推开近身小怪；升级扩大范围，达到装备Lv.5、人物Lv.20后可选独立觉醒，额外扩大范围、增伤，并在命中时每轮只为自己恢复2点生命。对Boss伤害为60%，不再触发流派连锁。
- **地上的烤鸡，还是能吃。** 原有45点恢复补给换上完整烤鸡像素图，继续按先到先得规则拾取。
- **有蒜你就来 / 这回真有吸血鬼。** 护符五级、墓园遇见吸血鬼各解锁一项新成就，分别奖励80和90金币，旧成就与已领金币保留。
- **天亮后的吐槽。** 通关统计底部会出现一行小彩蛋，和结算数据一起显示。

## 一局里能玩到什么

- **从小技能长成整套构筑。** 普攻、蓄力、战技、大招逐级进化；搭配配件解锁觉醒，再选择蓄力攻击的两条分支。
- **九个职业，九种战斗节奏。** 近战引爆流血、冰闪连锁控场、走位接回飞轮，锁定目标引导炮群轰炸，用圣域与羽翼阵支援队友，收集残魂带领亡军，玩台球连库、三式拳势，或四花轮转攒牌。
- **选三条流派，做自己的组合。** 七种流派中每局最多携带三种，配件最多三件。重刷优先给尚未出现的候选。
- **共享战场，掉落要抢。** 队友面对同一批怪物；经验水晶、金币、道具先到先得。每多一名玩家，怪物血量与掉落经验、金币增加 60%。
- **倒地还有下一次机会。** 队友站在尸体旁可救援；普通玩家一人需要 6 秒，两人一起 3 秒；祷师救援速度加倍，单人 3 秒，与一位普通队友协作 2 秒。倒地后可以切换队友视角。
- **随时结束本局，继续组队。** 房主在菜单点击「结束本局并返回队伍」，全员清空本局战场、回到同一个房间，保留房号、聊天和语音，再出征新一局。客人打开房间仍可返回当前战斗。
- **单人复活由自己确认。** 有破死重生次数时，倒地先显示3秒倒计时，再自行点击复活，恢复75%生命并获得3秒保护；不会自动站起。联机只使用队友救援，商店明确禁购仅限单人的复活天赋，已购等级保留。

## 天赋可以小步调整

圣殿中每项天赋都有「＋ / −」。加一级先显示所需金币，减一级按该级记录的实付金额退款，其他天赋保持；全局费用倍率与角色属性立即更新，仍可一键全部重置。联机不适用的单人复活天赋不能继续购买，但已购等级可以逐级退回。

旧存档没有逐次购买顺序时，按原来的已投入总额分配各级退款；退款总额保持，不凭空增加金币。新购买会保存每一级的实际金额。

结算评分表可直接在数据行上左右滑动，查看伤害、治疗、护盾及击杀/救援；竖向滚动仍可找到返回队伍和重新出征按钮。

### 三位新猎手，各自一套玩法

球爵每次碰撞反弹**保留100%伤害（无衰减）**，首次撞怪附带范围溅射，同球同敌最多3次；回弹重复命中不再反复触发流派。2技能与大招采用**环形星轨漩涡与多向瞄准激光交织冲击**特效，彻底告别生硬方框；大招期间加快普攻（间隔×0.65）与蓄力速度（耗时×0.60），并短暂提升同屏球数上限与38%弹射速度。拳师每拳命中的怪物都会额外被电击一次，大招六道雷门固定在地面持续高频电击范围内敌人，大招期间蓄力命中怪物更会在目标身上爆发范围雷暴。

牌师攒四张花色并在蓄力时按牌型变换华丽的立体扑克法阵与弹道：**同花**宽幅扇形齐射并追加两轮飞牌，**三条**全牌集中一列高速贯穿并连续三次点名，**两对**双翼扇形飞牌与自身护盾，**彩虹顺 / 王炸分支**触发360°全范围飞牌与范围裁决。前期普攻与蓄力发牌数量精简一半、随等级平滑成长至后期满屏火力；大招持续期间**自动加快蓄力速度（耗时×0.58）**，并大幅提升普攻与蓄力发牌数量与射程。手牌、锁花与鬼牌直接显示在状态栏。

### 第四关：锈月钟城

发条铜鼠、巡游齿轮、锈钥卫兵、铜面术师、铸钟巨兵与失时幽影组成30分钟波次。每5分钟迎战一位钟城首领，30分钟挑战终末钟王：交错时针、带缺口的钟波、时隙棋阵、夜轨双线、摆锤和返场终钟各有预警与躲避空间。六位首领均有两招及半血变化，也支持商人招募与死灵领主的原生招式。

![第四关的钟楼与发条魔物像素CG](assets/cg/rustmoon-clock-city.webp)

![满级机匠展开十座炮台与重装机甲，向尸潮发射交叉磁轨束](assets/screenshots/engineer-endgame.png)

*烬铁机匠：满级觉醒后 6 座常规炮台与 4 座大招支援形成十炮台阵地；自己和炮群共同释放金色磁轨束。*

机匠的战斗循环是 **铺炮网 → 普攻锁定并攒热 → 满热三轮集火 → 蓄力或过载轰炸**：

- 普攻升级为 6 枚贯穿锁定钉，每第三次觉醒普攻附带双追踪火箭；手持攻击指定炮群优先目标。
- 热能满时自动触发炮网三轮齐射；也可以提前蓄力，消耗已有热能强化重炮。
- 磁雷先牵引附近小怪，再延时爆破，把敌人聚进交叉火力范围。
- 蓄力二选一：**炮网贯穿齐射**让自己与全部炮台共同开炮；**追踪火箭弹幕**发射 6–10 枚弧线追踪火箭，并指挥炮群集火。
- 觉醒大招展开重装机甲与四座限时支援炮台，持续9秒巡航轰炸。浮游炮从Lv.1一门逐步成长为Lv.5四门，自动瞄准540px内的敌人，每0.45秒每门发射一枚爆炸弹，觉醒后每门两枚；大招期间普攻间隔×0.65，蓄满时间×0.70，结束恢复。常规炮台也有寿命，需要补充与调整阵地。

![机匠大招的四门浮游炮转向附近敌人，发射亮芯爆炸弹](assets/screenshots/engineer-cannons.png)

*浮游炮阵实机演示：缩小外围轮廓、移除粗支架，中心保留角色和走位空间。炮管瞄准与实际弹道共用方向；空场待机不假开火，开炮后才出现后坐、炮口焰和排烟。觉醒后使用双炮管，伤害仍由原有命中系统结算。*

## 购买最多两位Boss，让以前的对手替你开路

每人每局最多可购买**两位**首领友军，沉睡期间也占用名额。**死灵法师的召唤领主另算**，因此死灵法师可以同时拥有一位召唤领主和两位购买Boss。

- 购买Boss自主寻找敌人、接近与贴身攻击，复用24种首领的48套原版招式：冲锋、环形波、扇形吐息、弹幕、交错直线及原本的召唤招式。

## 曙光祷师：能救队友，也能独自打成型

## 喊朋友一起玩

1. 所有人用正常浏览器打开 **[在线版](https://582835293.github.io/darkest-pixel-survivor/)**，先点击「进入游戏」，再填写昵称、选择角色。
2. 房主创建公开房或密码房，朋友输入房号加入。也可以浏览公开房间列表，或快速匹配公开房。
3. 队伍到齐后点击“出征”。需要语音时打开“交流”，再点“开启麦克风”申请权限。

更新游戏后，所有队友确认同一版本，再重新开房。

房间支持命名、房号查重和人数限制。连接优先尝试 P2P 直连，大厅的“连接线路”会显示实际路径与往返延迟；房主可以选择备用线路。

- **交流能边打边看：** 文字默认以顶层弹幕显示；支持 WebRTC 语音、仅收听、静音和退出语音。
- **升级不用等队友：** 升级者暂时受到保护，有 20 秒选卡，超时随机选择；其他玩家继续战斗。
- **菜单与全队暂停分开：** 多人打开菜单只停止自己的操作，并获得最多 10 秒菜单无敌，切换嵌套菜单不重新计时。到期继续停在菜单仍会受伤。只有房主的专用按钮可以暂停、恢复整场对局。
- **方向和队友随时可查：** 屏幕边缘有队友箭头与距离，点击小地图可展开带距离圈的大地图。
- **特效与音量自己调：** “菜单 → 系统设置”分别调整自己/队友技能透明度、语音、音乐与音效音量。

## 操作

| 操作 | 电脑 | 手机 |
| --- | --- | --- |
| 移动 | WASD / 方向键 | 左侧摇杆 |
| 普攻 / 蓄力 | J / 空格，长按蓄力 | 点击 / 长按普攻 |
| 两项战技 | K / L | 对应技能按钮 |
| 终结技 / 护盾 | U / I | 对应技能按钮 |
| 菜单 | P / 右上角“菜单” | 右上角“菜单” |
| 访问附近商人 | E | 靠近后点击访问按钮 |

蓄力与连续黑洞爆炸不再震屏；大招、受伤和首领登场等关键事件保留最多3像素、0.12秒的轻微反馈，全局间隔至少0.65秒，后续事件不会延长当前震动。

可开启普攻连发辅助，把注意力留给走位与技能。出征与关闭菜单/聊天后自动归还战场焦点，并清除残留按键；兼容物理键位与旧式按键事件，聊天时不触发技能，切出窗口会清除按住状态。Chrome、Edge、Firefox已分别用正常动画循环测试九职业移动与K/L实际伤害。单人菜单会正常暂停。

多人开发者权限默认关闭，由房主在开发者面板设置本房间密码；客人验证后还需房主明确批准。换密码或关闭权限会撤销已有授权，退房后密码与授权清空。单人的隐藏口令不会出现在界面提示中。

## 存档与访问

返回营地会结束并清理本局，金币与永久天赋保留。“进入战场”始终开启新局，不再在营地显示“继续上次战局”。联机结算后保留队伍和语音。若浏览器意外关闭，可在“存档管理”手动恢复单人断点。

存档保存在**各自浏览器的 `localStorage`**，没有云存档。更新同一网址可继续使用原存档；换设备、浏览器、域名，或从本地 HTML 迁移时，可在“存档管理”导出完整 `PSSAVE_` 存档码，再到新环境导入。建议定期备份。

游戏本体是一个 HTML 文件，也可以下载 [index.html](index.html) 本地打开。手机文件预览器的 `content://` 环境可能无法申请麦克风权限，需要语音时请使用 HTTPS 在线版。

GitHub Pages 只分发游戏文件。P2P 连接取决于双方网络；公共备用线路没有服务质量保证，当前也未内置付费 TURN。具体机制、房号查重边界与线路说明见 [联网文档](docs/NETWORKING.md)。

## 开发与开源

游戏逻辑、界面、原版特效和像素精灵均在 [index.html](index.html) 中；游戏本体无需安装 npm 依赖。仓库检查覆盖真实本地 RTC、技能与伤害归属、房间、语音、存档、界面，以及原版/队友特效对比。

```bash
npm ci
npx playwright install chromium
npm run check
npm test
```

R30共40套592项回归（含16项重做、31项扩展、14项致敬专项，定向复测后通过）、Chrome / Edge / Firefox正常动画循环输入测试，见[验证记录](docs/TESTING.md)。九职业、四阶段、两种成型分支的180场固定靶数值实验，以及90场有真实移动与敌人伤害的短时遭遇战，见[平衡方法与数据](docs/BALANCE_R30.md)。这些检查不等于安卓真机跨网测试或真人30分钟通关；不会用短时DPS宣称所有构筑绝对平衡。

开发测试可通过 `PLAYWRIGHT_EXECUTABLE_PATH` 指定已有 Chromium / Edge。详见 [验证说明](docs/TESTING.md)；测试结果与临时画面保存在被 Git 忽略的 `test-results/`。

运行 `node scripts/capture-frontdoor-r30.cjs` 可重建标题页与四关预览，`node scripts/capture-r30.cjs` 可重建三位新角色的满构筑战斗截图，`node scripts/capture-r30-details.cjs` 单独展示其原生特效。五幅CG均内嵌HTML，单文件本地运行不需要图片服务器。

运行 `npm run icons` 可导出原创 PNG 图集及坐标表。运行 `npm run screenshots` 可重建首页的满级构筑演示图：通过真实升级卡配置角色，再生成怪潮并捕捉实时游戏画面。

运行 `node scripts/capture-r25.cjs` 可重建追猎脉冲、圣光普攻、商人、成就、图鉴与结算布局示例；结算示例使用预置统计，脚本不连接公开玩家房间。
