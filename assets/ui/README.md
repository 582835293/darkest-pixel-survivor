# 原创像素图标

132 枚原创图标，以 16×16 的整数像素绘制，使用钢铁、黄铜、血焰、冰晶与星辉配色。五个职业头像直接采用游戏角色精灵；武器、战技、道具、地图、菜单、聊天和语音均使用同一套图集。

图集和绘制代码采用仓库的 [MIT 许可证](../../LICENSE)，未使用第三方表情字体或素材包。

- `pixel-icons.png`：320×180 透明 PNG，每个格子 20×20，四边各留 2 像素。
- `pixel-icons.json`：各图标的语义名称、中文说明与 16×16 实际绘图区域坐标。
- [index.html](../../index.html) 的 `PixelIcons`：原始整数像素绘制代码，以及 DOM / Canvas 共用的图集渲染器。

运行 `npm run icons` 可重新导出图集。游戏运行时直接从内置代码生成并缓存图集，无需请求这两个文件，下载一个 HTML 仍可游玩。放大素材时应关闭平滑插值，使用最近邻缩放。

旧存档中的图标字符通过兼容表显示为像素图案；玩家自己发送的文字、表情与房间名称保持原文。
