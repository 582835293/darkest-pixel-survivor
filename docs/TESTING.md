# 验证说明

当前版本：v26.4 联机轻简版 R5。

57 项自动检查已通过：13 项房间目录、密码和匹配检查；11 项大厅、真实线路显示、弹幕与麦克风入口检查；14 项三人观战、文字和语音检查；19 项共享战场、掉落、救援、升级和暂停回归。

房间检查使用 8 个独立目录客户端和真实 Web Crypto，强制同时选择相同房号，验证冲突后的唯一房号和网络合并后的换号。浏览器检查覆盖密码格式、错误/正确密码、公开服务上不出现明文密码和流量密钥、未知成员隔离、公开房匹配、两人争最后一个空位、满员/过期过滤、取消匹配、退出释放空位、小屏布局及同浏览器原生 BroadcastChannel。

另用两份隔离浏览器通过实际公共消息线路建立临时密码测试房，完成查号、入房、加密战场快照及文字传输。此检查只代表开发电脑当时的网络，不能代替两个独立手机网络的时延测试。

覆盖了房主/客机观战、尸体坐标不变、复活后镜头归位、文字去重及丢失 ACK 修复、文本渲染、输入不触发攻击/暂停、两位收听者接收音频 RTP、第二位发言者、麦克风拒绝、静音、退出停止采音，以及申请权限期间取消后停止迟到的媒体轨道。

## 复现

需要 Node.js 18 或更新版本。游戏本体无需 npm 依赖；以下依赖只用于开发测试。

```bash
npm install
npx playwright install chromium
npm run check
npm test
```

可通过 `PLAYWRIGHT_EXECUTABLE_PATH` 指定本地 Chromium / Edge 可执行文件。测试结果与截图写入被 Git 忽略的 `test-results/`。

集成测试运行在回环地址的临时 HTTP 服务中，创建隔离的浏览器上下文，使用真实本地 WebRTC 数据/音频连接、模拟消息发现和虚拟麦克风，不接入玩家实际房间。麦克风 `content://` / 不安全上下文分支通过注入能力状态验证提示逻辑。

## 验证边界

- 虚拟麦克风只能验证浏览器采音与音频数据传输，不能代替安卓真机的音质、回声和权限操作。
- 本机回环连接不能证明两个独立手机运营商之间的 ICE 直连能力。
- 单个网络能访问静态站点，不代表所有地区、运营商均能访问。
- 切换麦克风的检查还模拟了旧 RTC 握手的 Promise 永不结束，确认新媒体会话不会被旧信令队列阻塞。
- 公共 MQTT、STUN、GitHub Pages 的可达性和服务质量不在本项目控制范围内。
