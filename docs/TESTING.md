## v1.0.0 验证说明

在原有 40 套 592 项回归校验基础上，v1.0.0 新增以下端到端与核心逻辑校验：
- **7 幅高压缩 WebP 关卡 CG 逐字节校验**（`scripts/check.mjs`）与 JS 语法完整校验。
- **多人神秘商人并发锁与回包幂等校验**：模拟双人同时点击商人、异常/重复错误回包与关闭清理，确认 `CampMarket.request` / `CampMarket.pending` 准确清除且不再刷屏“商人已离去”；确认卸下装备/流派按精确数值回滚属性。
- **多人 AI 机器人权威隔离与高频位姿平滑插值校验**：确认客机禁止本地 AI 驱动、隐藏客机端移除按钮、`CoopManager.remoteAllies()` 将机器人彻底排除在 WebRTC/心跳/聊天 ACK/世界分片队列之外，且 `CoopPoseWire` 支持 `bots` 紧凑位姿流往返编解码与客机 60FPS 平滑插值。
- **单技突破（`单技突破`）满级池校验**：确认全技能/流派/装备满级后仅产出单技突破卡（含 `lb_eq_garlicCharm` 蒜香护符突破与伤害成长），不再出现泛化兜底祝福卡，且禁用技能不进入突破池。
- **极端场景与性能防护校验**：验证 AI 机器人升级不污染房主属性/金币/弹窗、`addExp`/`healPlayer`/`damageEnemy` 的 `NaN`/`Infinity` 防护、`ExtraStages` 常规关卡不覆盖中帧属性、战局视野缩放（60%～140%）及自适应特效画质（保留 100% 数量仅精简绘制细节）。

## 复现

需要 Node.js 18 或更新版本。游戏本体无需 npm 依赖；以下依赖只用于开发测试。

```bash
npm install
npx playwright install chromium
npm run check
npm test
```

可通过 `PLAYWRIGHT_EXECUTABLE_PATH` 指定本地 Chromium / Edge 可执行文件。测试结果与截图写入被 Git 忽略的 `test-results/`。

集成测试运行在回环地址的临时 HTTP 服务中，创建隔离的浏览器上下文，使用真实本地 WebRTC 数据/音频连接、模拟消息发现和虚拟麦克风，不接入玩家实际房间。麦克风 `content://` / 不安全上下文分支通过注入能力状态验证提示逻辑。

- 虚拟麦克风只能验证浏览器采音与音频数据传输，不能代替安卓真机的音质、回声和权限操作。
- 本机回环连接不能证明两个独立手机运营商之间的 ICE 直连能力。
- 单个网络能访问静态站点，不代表所有地区、运营商均能访问。
- 切换麦克风的检查还模拟了旧 RTC 握手的 Promise 永不结束，确认新媒体会话不会被旧信令队列阻塞。
- 公共 MQTT、STUN、GitHub Pages 的可达性和服务质量不在本项目控制范围内。
