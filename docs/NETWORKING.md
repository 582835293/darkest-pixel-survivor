# 联网机制

## 数据路径

房间号用于通过公共信令/消息服务发现队友，交换 WebRTC 的连接信息；不是一台独占的游戏服务器。

浏览器使用 ICE 探测 IPv4/IPv6 路径，借助 STUN 获取候选地址，尝试建立玩家之间的 P2P 数据通道。具备全局 IPv6 候选仍可能受到防火墙、浏览器或运营商策略影响，需以实际数据通道应答为准。

直连成功时，移动和战场快照通过独立的低延迟数据通道传输，重要控制事件使用可靠通道。直连不可用时，尝试现有的公共 MQTT WebSocket 线路。

大厅的“当前”依据实际游戏数据路径显示，不依据房主选择的备用线路推测。直连延迟来自通道探测应答；未测得不填 0ms。多名队友的汇总延迟显示最慢值，展开可以查看每位队友。

公共服务可能限速、断开或在某些地区不可达。当前版本没有内置可靠 TURN 后备，因此不保证所有网络条件下均能建立 P2P 或实时游玩。

## 游戏同步

房主负责共享怪物、怪物死亡、战利品归属、救援和战局进度。客机使用插值和有限预测显示队友及怪物运动，按可见场景处理接触/弹道命中，再通过现有协议同步结算。

高频移动信息使用紧凑编码。世界快照按线路能力发送，支持压缩、分片与队列上限；积压时优先发送最新状态，避免旧快照持续拖慢画面。升级状态为玩家个人状态，手动暂停为全队状态。

## 文字与语音

文字走游戏的控制路径，带应用层送达确认、重试和去重。消息按文字渲染，不执行 HTML。弹幕只有本地动画，不增加广播频率；同屏和等待队列有上限。

语音为每对参与者建立独立 WebRTC 音频连接，不重新协商游戏连接。开启麦克风需要浏览器权限及受支持的安全上下文。手机 `content://` 文件预览入口可能不具备这些条件，应使用正常浏览器打开 HTTPS 在线版。

加入语音后可以只收听、静音或关闭本地播放。退出语音、离开房间或关闭页面时停止采音并清理媒体连接。语音是否能连接仍取决于媒体路径，不能仅凭游戏直连成功推断。

## 适用范围

本项目为朋友之间的合作游戏，没有账号认证、竞技反作弊或独占的房间服务。公开的短房号和公共消息代理不适合传递敏感信息，也不应当作具有访问权限控制的私密房间。

GitHub Pages 只分发静态文件。玩家存档和设置保存在本地浏览器，不自动上传到托管端。
