## 1. 核心战斗机制与全局成长公式

### 1.1 玩家伤害结算公式

当玩家或召唤物对敌方目标造成伤害时，实际扣血按以下流水线计算：

$$\text{FinalDamage} = \text{round}\Big(\text{BaseDamage} \times \text{LevelScale} \times \text{BuffMult} \times \text{VulnMult} \times \text{CritMult} \times \text{Variance}\Big)$$

| 乘区项 | 计算规则与参数说明 |
| :--- | :--- |
| **基础伤害 ($\text{BaseDamage}$)** | 技能/流派/秘宝当前的面板基数（已包含技能升级、圣殿天赋与局内突破倍率）。 |
| **角色等级增伤 ($\text{LevelScale}$)** | $1 + 0.065 \times (\text{PlayerLevel} - 1)$，每升 1 级全伤害提升 **6.5%**（主命中结算，次级流派伤害不重复叠加）。 |
| **战场增益 ($\text{BuffMult}$)** | 战神狂暴神龛激活时 $\times 1.65$；连斩暴走 (`berserkTimer`) 激活时额外加算。 |
| **目标易伤 ($\text{VulnMult}$)** | 中毒 (`poisonStacks`，最高 4 层)：每层使目标受到的伤害 $+6\%$（最高 $+24\%$）；黄金宝库金钱易伤 (`vaultVulnStacks`，最高 5 层)：每层额外易伤。 |
| **暴击乘区 ($\text{CritMult}$)** | 命中寒霜/冻结目标时，若拥有【极寒碎冰】流派，暴击率额外 $+20\%$；触发暴击时乘以 `player.critMultiplier`（基础 `1.75x`，可通过狂暴手套与天赋提升）。 |
| **随机浮动 ($\text{Variance}$)** | $0.92 \sim 1.08$（$\pm 8\%$ 随机微幅波动）。 |

### 1.2 玩家防御、护盾与天性自愈

- **护甲减伤 (`armor`)**：实际承伤 $= \text{RawDamage} \times (1 - \min(0.65, \text{armor}))$，总护甲上限为 **65%**。
- **护盾吸收 (`shield`)**：护盾优先于生命值抵扣伤害；基础护盾上限为最大生命的 **35%**，学习【星辉壁垒】或【猩红血棘】每级可额外提升 **+6% 最大生命** 的护盾上限（最高可达 **100% 最大生命**）。
- **角色天性·生命自愈**：每位猎手每 **10 秒** 自动恢复一定比例的最大生命值：
  - 曙光祷师 `4.0%` | 苍红剑客 `3.8%` | 风暴拳师 `3.6%` | 终局球爵 `3.2%` | 冥契术士 `3.0%` | 烬铁机匠 `2.8%` | 赤契牌师 `2.8%` | 暗夜巡林 `2.6%` | 星界魔导 `2.5%`。

### 1.3 六阶经验水晶动态合并（越合越大）与中后期经验加速

1. **六阶经验水晶体系 (`GEM_TIER_SPECS`)**：
   - 地面散落的经验水晶每 `0.35s` 自动聚拢合并，不仅提升品阶，还会根据合并次数 (`mergeCount`) 与累计经验值 (`expValue`) **持续放大晶体尺寸（最高可达 `24.0px`）**，高阶巨型水晶自带外环光晕与十字星芒切面：

| 品阶 | 名称 | 经验阈值 | 基础尺寸 → 最大合并尺寸 | 晶体配色 |
| :---: | :--- | :--- | :---: | :--- |
| **Tier 1** | 蓝水晶 | $1 \sim 3$ EXP | `4.6px` | `#38bdf8` (冰晶蓝) |
| **Tier 2** | 绿水晶 | $4 \sim 11$ EXP | `6.2px` | `#4ade80` (翡翠绿) |
| **Tier 3** | 红水晶 | $12 \sim 39$ EXP | `8.0px` | `#f43f5e` (绯红晶) |
| **Tier 4** | 金耀圣晶 | $40 \sim 139$ EXP | `10.0px` | `#fbbf24` (耀金晶) |

| **Tier 6** | 神耀源晶 | $\ge 450$ EXP | `14.5px → 24.0px` | `#fef08a` (神耀灿金) |

2. **中后期经验获取与升级曲线优化**：
   - **中后期怪物基础经验上调**：中期主力怪（Tier 2）基础经验提升至 `12～16`，后期精锐怪（Tier 3）基础经验提升至 `25～42`。
   - **时间经验倍率 (`expMul`)**：在常规时间成长基础上，3 分钟后与 8 分钟后分别开启二段与三段中后期经验加速：
     $$\text{expMul} = \big(1 + 0.24t + 0.018t^2 + \max(0, t-3)\times 0.24 + \max(0, t-8)^{1.35}\times 0.20\big) \times \text{CurseExpMul}$$
   - **分段平滑升级经验需求 (`expToNext`)**：
     - `Lv.1 ～ 9`：每级需求 $\times 1.20 + 6$
     - `Lv.10 ～ 17`：每级需求 $\times 1.14 + 5$
     - `Lv.18 ～ 27`：每级需求 $\times 1.10 + 4$
     - `Lv.28+`：每级需求 $\times 1.07 + 4$（彻底解决后期升级停滞问题）

### 6.2 波次 30 秒喘息渐强机制 (`waveRamp`)

  - 第 `0s → 30s`：刷新数量随时间线性攀升，在 30 秒时达到该波次的巅峰尸潮密度。

### 6.3 24 位首领（Boss）入场警戒与头顶跟随血条
- 四张主线地图在 **5 / 10 / 15 / 20 / 25 / 30 分钟** 各登场一位专属首领（共 24 位，每位均拥有 2 套独立招式与半血狂暴强化）。

- **头顶跟随血条**：Boss 血量直接跟随 Boss 头顶渲染为 **一行 10 格紧凑红框血条 + 无背景文字名称**，不占用手机屏幕上方 UI 空间，彻底避免与通知遮挡。

## 9. 局外养成、圣殿天赋退款与图鉴成就系统

1. **圣殿永久天赋 (`SaveManager.data.talents`)**：
   - 涵盖锋锐战刃（伤害）、龙鳞圣甲（最大生命）、疾风步（移速）、贪婪魔眼（拾取范围与金币）、蓄力大师（蓄力提速与增伤）、破死重生（单人手动确认复活）。
   - 支持 **「＋ / −」逐级加减与实付金额 100% 原路退款**，方便玩家随时微调构筑。
2. **铁匠铺神兵锻造 (`forge`)**：消耗金币永久强化武器阶位与暴击/破甲属性。
3. **防剧透全息图鉴与实时伤害排行榜**：
   - 包含 **英雄、魔物、首领** 三大分类，未解锁角色自动隐藏详情防剧透；局内打开暂停菜单「角色图鉴」可实时查看当前战局的 **总伤害、各技能/流派/秘宝伤害占比进度条与击杀统计**。
4. **45+ 项阶级成就**：完成即可一次性领取丰厚金币奖励，涵盖通关、流派满级、百万击杀、百亿累计伤害与彩蛋挑战。
