# R25受控数值记录

使用实际升级卡、冷却、召唤AI、伤害与流派代码。每场20秒，单体高生命目标和25目标密集群，六职业、四阶段（Lv.6/20/38/49）、两组固定种子；成型阶段分别测试A/B两种蓄力分支，共120场。没有天赋、诅咒、地图秘宝或商人友军，双方按相同选卡次数投入。每场混合普攻、蓄力、战技和大招。

死灵的前中期清群弱于部分范围职业，军团成型后的集中输出与范围斩击进入输出职业区间。祷师承担治疗与救援，纯输出较低。这些目标不会移动、躲避或击杀召唤物，实验也没有模拟不同网络延迟，不能把DPS表当作真人通关速度或全部流派的等强保证。

军团规则：最多12个，含1位领主；普通亡灵生命60%玩家、领主125%；数目增加会通过1/(1+0.055×(数量−1))降低单次伤害；亡军对敌方Boss再乘0.8。主命中触发全军共用0.18秒，普攻协同齐射共用1.2秒；继承周期秘宝的原有玩家周期，不复制12套定时器。常备骨仆14秒，大招小怪8+1.2×大招等级秒，领主12+大招等级秒。

初版实验发现军团中后期输出不足，因此增加成长、第三次普攻齐射和觉醒范围斩；随后压低对Boss的集火伤害。完整原始结果、种子、构筑清单、召唤物伤害分项与实际实验源码SHA见 [balance-r25.json](balance-r25.json)。后续只补充了召唤替换守卫和界面说明，不改变本表的伤害参数。

复现：`node scripts/balance-lab.cjs --label=r25 --seeds=2`。历史R21/R22资料仍保留在 [BALANCE.md](BALANCE.md)。
