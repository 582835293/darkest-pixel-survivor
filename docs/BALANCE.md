# R22 数值记录

本轮新增150场本版场景：100场单体/群体木桩与50场实际AI追击。五职业使用同档相同数量的真实升级卡（5/19/37/48张），无永久天赋、秘宝与诅咒，固定两个种子；成型档两种蓄力分支均参与。人物等级6/20/38/49，时间配置2/10/22/28分钟，仅为受控配置，不表示自然游玩必然达到该等级。R21的修改前后300场历史数据保留在后文。

木桩统计20秒实际扣血。单体位于65px处，群体为25只固定高血量目标；近距会放大散射集火和范围技能收益。AI追击为最多45秒、每两秒十只真实当期怪物、固定循环走位，不主动读预警或接回飞轮。两者都不能代表真人通关率，也不用于宣称五职业等强。

本版要点：祷师改为即时圣光，保留群疗、盾与双倍救援的辅助定位；大招五级成长；重叠领域可递减叠烧，最多等强单场两倍；接回每枚飞轮独立返还，可连续刷新。本测试AI未专门接轮，所以额外用实际六轮接取与多次施放专项核对无限刷新。追猎脉冲速度成长另由真实路径/双端RTC专项验证。

以下为两种子均值，成型档另合并A/B分支；群体列为25目标总伤害/秒，不能与单体列作为同一种战斗能力比较。治疗不计为伤害。

# R21 数值测试与调整

测试使用真实技能、弹道、领域和伤害函数，每档对全部职业投入相同数量的实际升级卡（5/19/35/46张），关闭永久天赋、秘宝和诅咒，固定两个随机种子。前/中/后/成型档采用2/10/22/28分钟怪物成长与Lv.6/20/36/47人物配置；这些是受控测试配置，不代表自然游玩必然在该分钟达到该等级。成型档同时测试两种蓄力分支。

木桩连续20秒：单体位于65px处，半径26；群体为25只固定位置的高血量怪物。混合普攻、蓄力、战技和大招；延迟技能使用模拟时钟。统计实际扣血而非飘字，木桩不会被秒杀。近距测试会放大散射弹与炮台集火收益，群体总伤害也会放大范围技能收益；它们不是实战每秒清怪数，不能单独用于给职业排名。

另做100场修改前后各50场的45秒追击遭遇战：真实当期怪物血量、AI和伤害，每两秒生成十只怪物，固定循环走位与技能轮转，无无敌；死亡即停止。记录击杀、死亡时刻、实际承伤及祷师有效治疗。这个固定策略不会读预警、主动接轮或守治疗阵，因此只能检查伤害/治疗/生存机制在活动目标上是否运行，不能代表真人存活率或通关率。

## 调整

- 祷师初始蓄力1.1秒改为0.7秒，释放间隔1.2秒改为0.735秒，并随等级、天赋和突破同步缩短；无天赋Lv.5蓄满约0.459秒，间隔约0.482秒。加快施放仍消耗全部祷光，空祷光不治疗。普攻每级额外提升10%的圣矢基数，蓄力等级系数由0.25提高至0.55；治疗单次量、护盾上限与救援效率不变。
- 法师和游侠各觉醒的直接伤害倍率1.65改为1.30；保留弹数、穿透、范围与主要形态。法师奥术首跳60%基数，后续每跳×0.82；星爆每目标0.45秒限频且不由二次伤害递归引爆。觉醒三重落星间隔0.22秒改为0.32秒，持续9秒和三颗彗星保留。
- 雷霆连锁从首击已结算伤害取比例后，不再重复乘暴击、等级、增伤神龛和中毒易伤。自身非火径熔岩领域对同一目标每0.3秒结算一次，取当帧到期领域中的最高伤害；业火流星保持独立限频。不同玩家独立结算自己的领域伤害。
- 游侠同一轮飞轮共享一次接取返还/回血奖励，防止六枚飞轮重复返还六份冷却。剑客与机匠基础技能系数保留；它们同样受共同结算修正影响。
- 玩家技能与秘宝冰冻对首领只施加寒霜，修复房主可硬冻首领而客机不行的差异；全图冻结道具保留。旧单人战局按版本迁移蓄力时长与法师/游侠觉醒系数，仅迁移一次。
- 电脑输入支持code/key/keyCode兼容，出征聚焦战场，聊天与失焦清理按键，长按不反复切菜单。真实键盘事件覆盖五职业WASD、方向键、J/空格、K/L、U/I及实际RTC客机。

共300场修改前后受控场景：200场木桩、100场真实AI遭遇战。结果保留职业定位差异，祷师还提供群疗、护盾及双倍救援；这不是“全部流派完全等强”的证明。
