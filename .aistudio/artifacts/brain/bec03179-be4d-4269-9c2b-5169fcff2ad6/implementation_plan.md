# 伤害统计精准化、技能突破重构与开发者菜单优化方案

## 1. 伤害统计系统重构与专属图标展示 (`DamageBreakdown`)
当前伤害统计依赖调用栈字符串猜测（`new Error().stack`）和被动持有状态兜底，导致延迟技能（如战士一技能冲锋延迟斩击、二技能环绕飞刃、大招延时陨落与熔岩区，以及法师/游侠/新英雄的持续区域与投射物）未被归入对应技能，反而误触了未拾取或被动的装备/秘宝词条。

- **显式伤害来源上下文 (`window.__withDmgSource(sourceId, fn)`) 与实体染色 (`dmgSource`)**：
  - 为所有投射物（`projectiles`、`orbitingBlades`、`boomerangs`、`NewHeroes` 弹道/法球/卡牌）、地面区域（`groundEffects`、`terrainBurns`）、延时回调（`setTimeout` / `NewHeroes.jobs`）和召唤物绑定明确的 `dmgSource` 标签。
  - **角色技能精准归因**：普攻（`basic`）、蓄力重击（`charge`）、一技能（`skill1`）、二技能（`skill2`）、终极技能（`ult`）的所有直接、延时与衍生区域伤害全部精准计入对应技能槽位。
  - **独立拆分异常状态与反伤统计**：
    - `status_reflect`：**反伤**（荆棘甲、星界壁垒等受击反弹伤害独立统计）
    - `status_bleed`：**流血**（锯齿匕首及技能附加的流血 DoT 独立统计）
    - `status_burn`：**灼烧**（熔岩之心、火焰轨迹、燃烧地面等灼烧 DoT 独立统计）
  - **死灵召唤物合并统计**：
    - `comp_necroSummon`：**死灵召唤物**（骷髅战士、骷髅法师、腐肉魔像、骨龙等所有死灵法师召唤物伤害统一合并为一项进行统计）。
  - **消除误判**：移除所有“只要或者未持有某被动就兜底归因给大蒜/熔岩之心/秘宝”的逻辑，严格仅在对应装备/秘宝实际触发伤害时记录。
- **全词条图标渲染**：
  - 为每个技能（根据当前英雄职业动态匹配专属像素图标）、流派共鸣、被动装备、秘宝、召唤物及状态伤害配置对应的 `[px:...]` 像素图标，并在局内暂停面板与结算面板渲染后调用 `PixelIcons.hydrate` 进行图标水合渲染。

## 2. 移除余烬回响触发时的技能名飘字 (`NewSynergies`)
- 在余烬回响（`emberEcho`）命中触发时，保留多层烈焰冲击波、火柱与火星粒子特效，移除 `createFloatingText(..., '🔥余烬回响!', ...)` 文字提示，避免画面杂乱。

## 3. 治疗量与护盾量统计补全 (`Campaign`)
- **治疗统计 (`healing`)**：
  - 在 `healPlayer(amount)` 中计算实际恢复的生命值增量（以及全满或部分恢复时的有效治疗量），将拾取焦香烤鸡（鸡腿）、吸血鬼獠牙、技能回血、生命药水等全部计入玩家本局的 **治疗 (`healing`)** 统计（兼容单人与联机客机同步）。
- **护盾统计 (`shielding`)**：
  - 在 `executeItem()`（旅者圣盾主动技能）、血契溢出转护盾、拳师二技能护盾、圣骑士/牧师护盾以及地图秘宝护盾生效时，将实际获得的护盾增量计入玩家本局的 **护盾 (`shielding`)** 统计。

## 4. 满级后技能突破（无限突破）纯数值化与 Bug 修复 (`generateUpgradePool` & 技能结算)
- **纯数值倍率成长，不改冷却与机制元素**：
  - 移除突破时对冷却时间（`cd` / `chargeMax`）、投射物数量、范围半径等复杂机制参数的修改，避免多元素叠加引发异常或失效。
  - 每次突破固定提升对应技能 **+25% 伤害/治疗/护盾数值倍率**（通过统一的 `getSkillBreakthroughMul(skillKey)` 辅助函数：`1 + 0.25 * (sk.limitBreak || 0)`）。
- **全职业与流派突破全覆盖**：
  - 修复蓄力重击（`charge`）、牧师治疗/护盾技能、工程师炮台/地雷/巨炮、死灵法师召唤物面板、以及 6 位新英雄技能在突破后数值未生效的问题。
  - 修复流派共鸣（`NEW_SYNERGIES` 等）突破时直接累加等级导致数组越界（`lv > 3`）的 Bug，改为独立记录突破层数 `player.synergyBreakthroughs[synKey]` 并纯粹放大该流派的伤害/护盾数值倍率。

## 5. 局外（营地大厅）与局内（战斗中）开发者菜单分离 (`CoopDev`)
- **动态场景识别**：根据当前是否处于战斗局内（`gameState === 'PLAYING' || gameState === 'PAUSED'` 等局内状态 vs 营地大厅）渲染不同的开发者面板：
  - **局外开发者菜单（营地大厅）**：仅保留 **增加金币 (`+10000 营地金币`)**、**全解锁 (`解锁全英雄/关卡/特权/图鉴`)** 与 **存档重置 (`重置全部本地存档`)**。
  - **局内开发者菜单（战斗中）**：保留 **角色升级 (`升 1 级` / `升 5 级`)**、**技能与突破 (`全技能满级` / `立即自选升级`)**、**召唤首领 (`召唤精英首领` / `召唤最终首领`)** 与 **无敌开关 (`开启/关闭无敌模式`)**。
